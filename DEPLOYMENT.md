# Deploying Jivdani Vegetable Suppliers on VPS

**VPS IP:** `45.196.196.114`  
**Domain:** `app.mmpf.in`  
**Stack:** FastAPI + MongoDB + React → served by Caddy (auto-HTTPS)

---

## First-time VPS Setup

```bash
# SSH into VPS as root
ssh root@45.196.196.114

# Download & run setup script (installs Docker, clones repo, creates .env)
bash <(curl -fsSL https://raw.githubusercontent.com/shubhamshirve/JVSapp/main/scripts/vps_setup.sh)
```

### After setup, edit the .env:
```bash
nano /opt/jvsapp/.env
```

Set your values (JWT_SECRET is auto-generated, only change the password):
```env
SITE_ADDRESS=app.mmpf.in
SITE_URL=https://app.mmpf.in
DB_NAME=jivdani
JWT_SECRET=<auto-generated, keep as-is or regenerate>
ADMIN_EMAIL=admin@jivdani.com
ADMIN_PASSWORD=<your-strong-password>
```

### First build & start:
```bash
cd /opt/jvsapp
docker compose up -d --build
```

> Caddy will automatically obtain a TLS certificate for `app.mmpf.in` via Let's Encrypt  
> Make sure DNS `A` record for `app.mmpf.in` points to `45.196.196.114` before starting

## GitHub Actions CI/CD (Recommended)

Every push to `main` automatically builds images on GitHub and deploys to VPS.

### Required GitHub Secrets:
| Secret | Value |
|--------|-------|
| `VPS_HOST` | `45.196.196.114` |
| `VPS_USER` | `root` |
| `SSH_PRIVATE_KEY` | Your SSH private key (from `~/.ssh/id_rsa`) |

### Setup SSH key:
```bash
# On your local machine
ssh-keygen -t ed25519 -C "github-deploy"
# Add public key to VPS:
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@45.196.196.114
# Add private key (~/.ssh/id_ed25519) as SSH_PRIVATE_KEY secret in GitHub
```

## Common Commands

```bash
# View logs
docker compose logs -f backend
docker compose logs -f caddy

# Restart a service
docker compose restart backend

# Check status
docker compose ps

# Stop everything (data preserved)
docker compose down

# Stop AND delete all data (DANGER)
docker compose down -v
```

## Backup Database

```bash
# Backup
docker compose exec mongo mongodump --db jivdani --archive=/tmp/backup.archive
docker cp $(docker compose ps -q mongo):/tmp/backup.archive ./jivdani-backup.archive

# Restore
docker cp ./jivdani-backup.archive $(docker compose ps -q mongo):/tmp/backup.archive
docker compose exec mongo mongorestore --archive=/tmp/backup.archive
```

## Architecture

```
browser → HTTPS (Caddy:443)
           ├── /api/* → backend:8001 (FastAPI)
           └── /*     → /srv/index.html (React SPA)
                              └── backend → mongo:27017
```

- No exposed ports except 80/443 (all traffic through Caddy)
- TLS certificate auto-renewed by Caddy (stored in `caddy_data` volume)
- MongoDB data in `mongo_data` volume (persists across restarts)
